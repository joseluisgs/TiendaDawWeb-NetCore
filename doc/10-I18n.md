## 10.1. Configuración

### Program.cs

```csharp
builder.Services.AddLocalization(options => 
    options.ResourcesPath = "Resources");

var supportedCultures = new[] { "es", "en", "fr", "de" };
builder.Services.Configure<RequestLocalizationOptions>(options =>
{
    options.SetDefaultCulture("es")
           .AddSupportedCultures(supportedCultures)
           .AddSupportedUICultures(supportedCultures);
    
    options.ApplyCurrentCultureToResponseHeaders = true;
});

var app = builder.Build();

app.UseRequestLocalization();
```

### Middleware de Localización

```csharp
var localizationOptions = new RequestLocalizationOptions()
    .SetDefaultCulture("es")
    .AddSupportedCultures("es", "en", "fr")
    .AddSupportedUICultures("es", "en", "fr");

app.UseRequestLocalization(localizationOptions);
```

## 10.2. Recursos y Archivos

### Estructura de Recursos

```
Resources/
├── Controllers/
│   ├── ProductsController.es.resx
│   └── ProductsController.en.resx
├── Views/
│   ├── Shared/
│   │   └── _Layout.es.resx
│   └── Products/
│       ├── Index.es.resx
│       └── Details.es.resx
└── Pages/
    └── _ValidationScriptsPartial.es.resx
```

### Archivo de Recursos (.resx)

```xml
<!-- Resources/Views/Products/Index.es.resx -->
<data name="Title" xml:space="preserve">
    <value>Catálogo de Productos</value>
</data>

<data name="SearchPlaceholder" xml:space="preserve">
    <value>Buscar productos...</value>
</data>

<data name="AddProduct" xml:space="preserve">
    <value>Nuevo Producto</value>
</data>

<data name="PriceFormat" xml:space="preserve">
    <value>Precio: {0}</value>
</data>
```

## 10.3. Uso en Vistas

### IHtmlLocalizer

```html
@inject IHtmlLocalizer<HomeController> Localizer

<h1>@Localizer["Welcome"]</h1>
<p>@Localizer["TodayIs", DateTime.Now]</p>
<p>@Localizer["PriceFormat", product.Precio]</p>
```

### IStringLocalizer

```csharp
@page "/products"
@model ProductsModel
@inject IStringLocalizer<ProductsModel> Localizer

<h1>@Localizer["ProductsList"]</h1>

@if (!Model.Products.Any())
{
    <p>@Localizer["NoProductsFound"]</p>
}
```

### Con ViewData

```csharp
public IActionResult Index()
{
    ViewData["Title"] = _localizer["ProductsTitle"];
    ViewData["SearchPlaceholder"] = _localizer["SearchPlaceholder"];
    
    return View();
}
```

```html
@{
    var title = ViewData["Title"] as string;
}
<h1>@title</h1>
```

## 10.4. Culture Selection

### Selector de Idioma en UI

```html
<form asp-controller="Culture" asp-action="SetCulture" method="post">
    <input type="hidden" name="culture" value="@culture" />
    <select name="returnUrl" onchange="this.form.submit()">
        <option value="/" selected>Español</option>
        <option value="/en/">English</option>
        <option value="/fr/">Français</option>
    </select>
</form>
```

### Culture Controller

```csharp
[Route("[controller]/[action]")]
public class CultureController : Controller
{
    public IActionResult SetCulture(string culture, string returnUrl)
    {
        Response.Cookies.Append(
            CookieRequestCultureProvider.DefaultCookieName,
            CookieRequestCultureProvider.MakeCookieValue(
                new RequestCulture(culture)),
            new CookieOptions { Expires = DateTimeOffset.UtcNow.AddYears(1) }
        );

        return LocalRedirect(returnUrl ?? "/");
    }
}
```

### Obtener Culture Actual

```csharp
// En cualquier lugar
var culture = Thread.CurrentThread.CurrentCulture.Name;

// En Controller
var currentCulture = RequestCultureProvider.GetCurrentCulture();

// En Vista
@Thread.CurrentThread.CurrentCulture.Name
@Thread.CurrentThread.CurrentUICulture.Name
```

## 10.5. Resumen

| Concepto                   | Descripción                                              |
| -------------------------- | ------------------------------------------------------- |
| **IStringLocalizer**      | Localización de texto plano                            |
| **IHtmlLocalizer**        | Localización con soporte HTML                          |
| **RequestLocalization**   | Middleware para detectar cultura del usuario            |
| **.resx Files**           | Archivos de recursos por idioma                         |
| **Culture Cookie**        | Cookie que guarda la preferencia de idioma              |
